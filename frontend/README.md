# Frontend

Vue 3 + TypeScript + Vite SPA. Инструкции по запуску, командам и архитектуре — в
[корневом README.md](../README.md) и [specs/001-music-catalog/plan.md](../specs/001-music-catalog/plan.md).

Быстрые команды (после `npm install`):

```bash
npm run dev         # dev-сервер с проксированием /api на backend
npm run build        # production-сборка (включает vue-tsc)
npm run test         # Vitest
npm run lint          # ESLint
npm run typecheck    # vue-tsc --noEmit
```
